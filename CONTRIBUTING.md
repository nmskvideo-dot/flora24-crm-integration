# Contribuição (Внесок у розвиток)

Спасибо за интерес к нашему проекту! Здесь вы найдете правила и рекомендации для внесения вклада.

## 📋 Процесс внесения изменений

### 1. Создайте Issue
Прежде всего, создайте GitHub Issue с описанием:
- Что вы хотите добавить/исправить
- Почему это необходимо
- Какие тесты вы проводили

### 2. Fork Репозитория
```bash
git clone https://github.com/YOUR_USERNAME/flora24-crm-integration.git
cd flora24-crm-integration
git checkout -b feature/название-функции
```

### 3. Внесите изменения
- Следуйте стилю кода проекта
- Добавляйте комментарии на русском/украинском
- Обновляйте документацию при необходимости

### 4. Тестирование
- Протестируйте на локальном сервере WordPress
- Убедитесь, что нет конфликтов с другими плагинами
- Проверьте логирование и обработку ошибок

### 5. Commit и Push
```bash
git add .
git commit -m "Описание изменения - fix: исправлено логирование API"
git push origin feature/название-функции
```

### 6. Pull Request
Создайте PR с полным описанием изменений.

## 🎨 Стиль кода

### PHP стиль
```php
// Используйте функции WordPress
add_action('hook_name', 'function_name');
add_filter('filter_name', 'filter_function');

// Документируйте функции
/**
 * Синхронизирует товар с Flora24
 *
 * @param int $product_id ID товара WooCommerce
 * @param string $flora_id ID товара Flora24
 * @return bool
 */
function sync_product($product_id, $flora_id) {
    // ...
}

// Используйте проверки безопасности
if (!current_user_can('manage_woocommerce')) {
    wp_die('Access denied');
}
```

### Имена функций
- Используйте префикс `mflowers_flora24_`
- Используйте snake_case: `my_function_name()`

### Комментарии
- На русском/украинском языке
- Объясняйте ПОЧЕМУ, а не ЧТО

## 📝 Типы коммитов

```
feat:   Новая функция
fix:    Исправление ошибки
docs:   Документация
style:  Форматирование кода
refactor: Рефакторинг без смены функциональности
perf:   Улучшение производительности
test:   Добавление тестов
chore:  Изменения в инструментах сборки
```

Пример:
```
feat: добавлена поддержка вложенных продуктов Flora24
fix: исправлена ошибка при парсинге JSON ответа
docs: обновлен README с новыми примерами
```

## 💡 Рекомендации

### Перед разработкой
- ✅ Проверьте существующие Issues
- ✅ Убедитесь, что это не дублирует существующий функционал
- ✅ Обсудите большие изменения сначала в Issue

### Во время разработки
- ✅ Пишите понятный код с комментариями
- ✅ Используйте функции WordPress вместо PHP
- ✅ Следуйте security best practices
- ✅ Регулярно коммитьте (не 1 огромный коммит)

### После разработки
- ✅ Обновите CHANGELOG.md
- ✅ Обновите README если добавлены новые функции
- ✅ Напишите ясное описание PR

## 🚀 Процесс Review

1. **Автоматические проверки** — код должен быть понятным
2. **Ревью мейнтейнера** — проверка логики и стиля
3. **Финальное утверждение** — проверка совместимости
4. **Мёрж** — объединение в main ветку

## 📚 Документация

При добавлении новой функции обновите:
- `README.md` — описание функции для пользователей
- `CHANGELOG.md` — версия и короткое описание
- Комментарии в коде — для разработчиков
