# Changelog

Все значительные изменения этого проекта будут документированы в этом файле.

## [1.5.0] - 2026

### Added
- 🆕 Встроенное редактирование Flora24 ID в списке товаров WooCommerce
- 🆕 Метабокс для Flora24 ID на странице редактирования товара (под полем SKU)
- 🆕 Пользовательская колонка "Flora24 ID" в таблице товаров
- 🆕 AJAX обработчик для быстрого сохранения ID с визуальной обратной связью
- 🆕 Статус индикатор (✓ Збережено / Помилка) при редактировании ID

### Improved
- ⚡ Улучшена скорость добавления Flora24 ID к товарам
- 💾 Прямое редактирование без переходов между страницами
- 🎨 Лучший UX для управления Flora24 ID

## [1.4.2] - 2024-2026

### Added
- ✨ Полная поддержка интеграции с Action Scheduler для надежного крона
- 📊 Расширенная система логирования с сохранением файлов по датам
- 🎨 Красивая консоль с цветным кодом состояния операций
- 🔍 Мастер-сканирование товаров с Flora24 ID
- 📋 Таблица со статусом валидации каждого товара
- ⚡ Батч-обработка для массовой синхронизации
- 📁 Архив логов с просмотром истории за 30 дней
- 🔐 Поле пароля для безопасного хранения API ключа

### Improved
- 🚀 Оптимизирована скорость синхронизации массивов товаров
- 💾 Улучшена обработка ошибок API
- 📝 Детальное логирование каждого шага синхронизации
- 🔄 Автоматическое удаление старых логов (более 30 дней)
- ✅ Лучшая валидация Flora24 ID

### Security
- 🔐 Использование WordPress nonce для CSRF защиты
- 🛡️ Санитизация всех входных данных
- 👮 Проверка прав доступа на каждом шаге
- 🔒 Зашифрованное хранение API ключа
