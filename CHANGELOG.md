# Changelog

Все значительные изменения этого проекта будут документированы в этом файле.

## [1.6.1] - 2026-07-02

### Security 🔐
- ✅ **Nonce CSRF защита в AJAX запросах** — добавлены проверочные токены (`wp_create_nonce` и `check_ajax_referer`) для всех AJAX действий, включая быстрое редактирование ID в таблице товаров и кнопки управления в панели
- ✅ **Ограничение чтения логов** — строгая валидация имён файлов логов через регулярное выражение `/^sync-\d{4}-\d{2}-\d{2}\.log$/`, что полностью блокирует попытки path traversal атак
- ✅ **Защита от memory overflow при загрузке логов** — файлы, превышающие 2 МБ, не загружаются в память; вместо этого выводится предупреждение со ссылкой на загрузку через FTP/SSH
- ✅ **Валидация структуры API ответа** — жёсткие проверки наличия обязательных ключей `price` и `active` перед обращением к ним, что предотвращает PHP Warnings и Errors
- ✅ **Mutex-блокировка конкурентных синхронизаций** — использование WordPress транзиентов (`set_transient` с таймаутом 5 минут) для атомарных замков; вторая синхронизация мягко завершится уведомлением, защищая от race conditions и дублирования запросов

### Performance ⚡
- ✅ **Оптимизация API запросов через batch-кэширование** — при массовом редактировании нескольких товаров ответ API скачивается **всего один раз** за первый запрос, сохраняется во временный транзиент на 2 минуты, и остальные товары обрабатываются локально без доп. нагрузки на сеть и CRM

### Improved
- 🔄 Оптимизирована архитектура sync-lock для обоих контекстов (AJAX и Cron)
- 📝 Расширено логирование для лучшей диагностики конфликтов
