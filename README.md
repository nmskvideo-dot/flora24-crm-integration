# Flora24 CRM Integration for MFlowers

WordPress плагин для синхронизации цен та доступності товарів з CRM Flora24 у WooCommerce магазин.

## 📋 Описание

**Flora24 CRM Integration** — это профессиональный WordPress плагин, разработанный для интеграции WooCommerce-магазина с системой управления CRM Flora24. Плагин обеспечивает полностью автоматизированную синхронизацию:

- **Цены товаров** — автоматическое обновление в реальном времени
- **Доступность (наличие)** — мониторинг статуса товаров в CRM
- **Расширенное логирование** — детальное отслеживание всех операций
- **Гибкая настройка** — управление интервалом синхронизации
- **Мастер-консоль** — удобный интерфейс администратора для контроля

## ✨ Основные возможности

### Автоматическая синхронизация (Cron)
- Настраиваемая периодичность синхронизации (от 15 минут до 2 дней)
- Использует ActionScheduler для надежного выполнения фоновых задач
- Автоматический мониторинг всех товаров с ID Flora24
- Интеллектуальный пропуск не измененных товаров для оптимизации

### Управление товарами
- **Сканирование базы** — поиск всех товаров с Flora24 ID
- **Ручная синхронизация** — обновление одного или нескольких товаров на выбор
- **Батч-обработка** — массовое обновление выбранных товаров
- **Валидация ID** — проверка корректности Flora24 ID (формат: PRD-xxx или ПРД-xxx)

### Логирование и отладка
- **Дневные логи** — автоматическое сохранение файлов логов
- **Консоль операций** — живой просмотр всех операций
- **Архив логов** — просмотр истории за последние 30 дней
- **Подробные отчеты** — информация о каждом обновлении товара

### Цветной код состояния
- 🟢 **Зеленый** — успешная синхронизация
- 🔵 **Синий** — информационные сообщения
- 🟡 **Желтый** — запуск процесса
- 🔴 **Красный** — ошибки и критические события

## 🛠️ Требования

- **WordPress:** 5.0+
- **WooCommerce:** 4.0+
- **PHP:** 7.2+ (рекомендуется 7.4+)
- **Action Scheduler:** плагин должен быть установлен (обычно входит в комплект WooCommerce)
- **Доступ в интернет:** для подключения к Flora24 API

## 📦 Установка

### Способ 1: Загрузка плагина вручную
1. Скачайте файл `flora24-crm-integration.php`
2. Перейдите в WordPress Панель управления → **Плагины → Добавить новый**
3. Нажмите **Загрузить плагин** и выберите скачанный файл
4. Нажмите **Установить сейчас**
5. После установки нажмите **Активировать плагин**

### Способ 2: FTP загрузка
1. Подключитесь к серверу по FTP
2. Перейдите в папку `/wp-content/plugins/`
3. Создайте новую папку `flora24-crm-integration`
4. Загрузите файл `flora24-crm-integration.php` в эту папку
5. В WordPress Панель управления → **Плагины** найдите плагин и нажмите **Активировать**

## 🔧 Настройка

### 1️⃣ Получение API ключа
1. Авторизуйтесь на [Flora24](https://flora24.online/)
2. Перейдите в раздел **API & Интеграции**
3. Скопируйте ваш **X-API-Key**

### 2️⃣ Конфигурация плагина
1. В WordPress перейдите в **Параметры → Flora 24**
2. Введите скопированный **X-API-Key** в поле авторизации
3. Включите опцию **Автоматическая синхронизация в фоне** (опционально)
4. Выберите оптимальный интервал синхронизации (рекомендуется **1 час**)
5. Нажмите **Сберегти налаштування**

### 3️⃣ Добавление Flora24 ID к товарам
Каждому товару, который нужно синхронизировать, необходимо добавить **Flora24 ID**:
1. Перейдите в **WooCommerce → Товары**
2. Откройте товар на редактирование
3. Найдите поле **Flora24 ID** (обычно в разделе дополнительных данных)
4. Введите ID товара из Flora24 (формат: `PRD-xxx` или `ПРД-xxx`)
5. Сохраните товар

## 📊 Использование

### Ручная синхронизация
1. Перейдите в **Параметры → Flora 24**
2. Нажмите кнопку **Знайти товари з Flora24 ID**
3. Плагин отсканирует базу и выведет все товары с ID Flora24
4. Можно выбрать товары и нажать **Синхронізувати вибрані**
5. Или нажать кнопку **Оновити** рядом с отдельным товаром

### Просмотр логов
1. В той же странице **Параметры → Flora 24** внизу находится **Консоль оновлення**
2. Выберите дату лога из выпадающего списка
3. Нажмите **Завантажити лог** для просмотра полной истории

### Автоматическая синхронизация (Cron)
1. Убедитесь, что включена опция **Автоматическая синхронизация**
2. Установите нужный интервал (рекомендуется 1-3 часа для средних магазинов)
3. Плагин будет автоматически обновлять товары в фоне

## ⚙️ Расширенная конфигурация

### Интервалы синхронизации
- **Кожні 15 хвилин** — для очень активных каталогов (большая нагрузка на сервер)
- **Кожні 30 хвилин** — для магазинов с частыми изменениями
- **Кожну годину** ⭐ **РЕКОМЕНДОВАНО** — оптимальный баланс
- **Кожні 2-12 годин** — для стабильных каталогов
- **Раз на добу** — для магазинов с редкими изменениями

### Требования к серверу
- **Cron-задачи** должны быть включены (обычно включены по умолчанию)
- **Action Scheduler** должен иметь доступ к БД
- **API Flora24** должна быть доступна с вашего сервера

## 🐛 Решение проблем

### Проблема: API ключ не принимается
**Решение:**
- Убедитесь, что ключ скопирован полностью без пробелов
- Проверьте, что ключ еще активен в кабинете Flora24
- Попробуйте выйти и войти снова в аккаунт Flora24

### Проблема: Товары не синхронизируются
**Решение:**
- Проверьте, что товары имеют правильный формат Flora24 ID (PRD-xxx)
- Убедитесь, что товары существуют в вашем кабинете Flora24
- Проверьте логи в **Консоли оновлення** для деталей ошибок
- Убедитесь, что на сервере включены WordPress Cron-задачи

### Проблема: Медленная синхронизация
**Решение:**
- Увеличьте интервал синхронизации (установите 2-3 часа вместо 1)
- Проверьте скорость подключения к Flora24 API
- Рассмотрите возможность оптимизации базы данных WordPress

### Проблема: Логи не сохраняются
**Решение:**
- Проверьте, что папка `/wp-content/uploads/flora24-logs/` существует
- Убедитесь, что у сервера есть права на запись в эту папку (755 для Linux)
- Проверьте, что на диске достаточно свободного места

## 📝 Структура логов

Логи сохраняются в формате:
```
[HH:MM:SS] [Сообщение операции]
```

Пример:
```
[14:23:45] Запуск масової синхронізації для 5 товарів...
[14:23:47] Товар ID 1234 (Flora ID: PRD-ABC123) [Букет "春"]: Ціна: [250 грн -> 280 грн] | Наявність: [В наявності -> Немає]
[14:23:50] Авто-Крон | Товар ID 1235 (Flora ID: PRD-XYZ789) [Букет "Сакура"]: Синхронізовано успішно
```

## 🔐 Безопасность

- **API ключ** — сохраняется в зашифрованном виде в БД WordPress
- **Проверки прав** — только пользователи с правами `manage_woocommerce` имеют доступ
- **CSRF защита** — используются WordPress nonce для всех форм
- **Sanitization** — все входные данные проходят валидацию и очистку
- **Старые логи** — автоматически удаляются через 30 дней
